# Tab

Tab finds the wasted portion of your token spend — itemized, with fixes — and
tells you what each outcome actually cost you in quota.

This is a Phase 0 scaffold. Only the version banner command is wired:

- `/tab` — print the version banner.

Later phases add `/tab waste`, `/tab report`, and `/tab forecast`. See
`design/TAB_TECH_SPEC.md` for the full specification.
